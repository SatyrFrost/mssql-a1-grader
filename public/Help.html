Help & Support

Welcome to the help section for the App Portal. Here you'll find information and guidance on using the various tools available.

ERD Grader

The ERD Grader allows you to upload your draw.io XML files to automatically grade your Entity-Relationship Diagrams. Ensure your XML file is exported correctly from draw.io.

  • File Format: Only .xml or .drawio files are accepted.
  • Grading Criteria: The grader checks for correct entities, attributes, primary keys (PK), foreign keys (FK), and relationships with their cardinalities.
  • Troubleshooting: If you encounter parsing errors, double-check your draw.io file for any structural issues or non-standard elements.

Data Dictionary Builder

This external tool helps you build and manage data dictionaries for your database designs. Click the link on the homepage to access it.

DD Teacher Grading Page

An external tool specifically for teachers to grade data dictionary assignments. This is only accessible when logged in as a teacher.

SQL Grader for Teachers

Another external tool for teachers to grade SQL assignments. This is also only accessible when logged in as a teacher.
